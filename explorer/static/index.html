Gemma 3n · Per-Layer Embeddings

Every layer gets its own embedding of every token.

A PLE table E of shape [V, L·p] stores one small vector per token per layer. It is only ever indexed, never multiplied, so it can live in CPU RAM or flash and stream in a few hundred bytes per token. Scroll to follow one token through the model.

  1. 01

    A token arrives

    The tokenizer turns ·dog into the integer t. That id is known before the forward pass starts, which is what makes prefetching a table row possible.

  2. 02

    Look up one row

    The PLE table E has 50,304 rows of 384 numbers (19.3M parameters in ple-small). The model reads exactly one row, E[t]. No matrix multiply touches the table.

  3. 03

    Split it into slices

    The row is reshaped to [6, 64]: one slice of 64 numbers for each of the 6 layers, scaled by √p. Each layer gets its own, unrelated vector. Across frequent tokens the cosine between layers is about 0.

  4. 04

    Mix in context

    Each slice is averaged with a projection of the normal input embedding x₀, so the layer sees both the token identity and the embedding space:

    ul= E[t]l · √p · maskl + RMSNorm(Wctx x0 d−½)l√2
  5. 05

    Gate it

    After its attention and MLP sublayers, block l computes a gate from its residual stream h and multiplies it element-wise with ul. The gate decides how much to read; the slice decides what.

    gl=gelu(Wgate h)⊙ul
  6. 06

    Add it to the stream

    The gated vector is projected back to d = 384, normalised and added to the residual stream, in all 6 layers:

    h←h+RMSNorm( Wproj · gl )

    Ablation in this explorer sets maskl = 0: the token part disappears, the context part stays.

Reading the views

  • Norms: slices start at norm ≈ 0.02·p; rows that never appear in training stay there, so the norm is a proxy for "how trained" a token is.
  • Neighbours: tokens with similar slices in a layer are treated alike by that layer's PLE path. Full rows are cleanly semantic: ·happy → glad, lucky, cheerful.
  • Gate magnitude: mean |gelu(Wgateh)|. High = the layer is reading a lot of this token's slice at this position.
  • Contribution ratio: size of the PLE update relative to the residual stream; how loudly PLE "speaks" in each layer.
  • Δloss: ablated − normal loss. Orange tokens got harder to predict without PLE, so the model relies on PLE for them.

The 0.009 val-loss gap to the baseline is within single-seed noise. See docs/EXPLORER.md for details.
